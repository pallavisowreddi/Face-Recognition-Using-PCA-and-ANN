# Face-Recognition-Using-PCA-and-ANN
Face Recognition System using Principal Component Analysis (PCA) and Artificial Neural Networks (ANN). This project focuses on facial feature extraction, dimensionality reduction, and accurate face classification using Machine Learning techniques implemented in Python and Google Colab.



# Face Recognition using PCA and Artificial Neural Networks (ANN)
## Overview

This project presents an AI-based Face Recognition System developed using Principal Component Analysis (PCA) and Artificial Neural Networks (ANN). The primary objective of the project is to improve facial recognition accuracy by reducing image dimensionality through PCA and performing classification using ANN.

The project demonstrates the practical implementation of Machine Learning techniques in biometric authentication and intelligent recognition systems.

## Internship Information
This project was completed as part of an AI/ML Internship Program, focusing on the practical application of Machine Learning concepts for Face Recognition and Intelligent Classification Systems.

## Objectives
* Develop an efficient face recognition model using Machine Learning
* Apply Principal Component Analysis (PCA) for feature extraction and dimensionality reduction
* Train an Artificial Neural Network (ANN) for facial image classification
* Evaluate model performance and prediction accuracy

## Methodology
### 1. Data Preprocessing
* Imported and cleaned facial image datasets
* Converted image data into suitable numerical format
* Split data into training and testing datasets

### 2. Feature Extraction using PCA
* Reduced high-dimensional image data
* Extracted important facial features
* Improved computational efficiency and reduced redundancy

### 3. ANN Model Development
* Designed and trained an Artificial Neural Network
* Learned facial feature patterns from PCA-transformed data
* Performed classification and prediction tasks

### 4. Model Evaluation
* Tested the trained model on unseen data
* Evaluated recognition accuracy and prediction performance
